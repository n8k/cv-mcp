Connect it

Claude

claude.ai on the web or the desktop app

  1. Open Settings → Connectors and choose Add custom connector.
  2. Give it a name (for example CV-MCP), paste the server URL, and leave the authentication fields empty.
  3. Start a new chat, open the tools menu under the message box, and switch the connector on.
  4. Ask a question. Claude asks before its first tool call; every tool is read-only, so "Always allow" is safe.

On Team and Enterprise plans an owner may need to allow custom connectors first.

Microsoft Copilot Studio

for an agent in your organisation's tenant

  1. Open your agent and go to Tools → Add a tool.
  2. Choose Model Context Protocol and paste the server URL.
  3. Set authentication to None, then save and add the tool to the agent.
  4. Test it in the agent's test pane with one of the prompts below.

Menu names can differ by version, and some tenants block external MCP servers. If yours does, a live demo in Claude works just as well.

Try asking

  • Introduce $first_name in a short paragraph, then list the case studies with one line each.
  • Tell me, in STAR format, about a time $first_name changed how an organisation works.
  • Give me a STAR example of $first_name using AI or automation to save leadership time.
  • Walk me through the largest delivery programme as Situation, Task, Action and Result.
  • Here is our job description: [paste it]. Assess the fit criterion by criterion, back up each strong rating with the most relevant case study, and show the gaps.
  • Using the CV tools only, write three behavioural interview questions for this role, each tied to one of the case studies.

Start a fresh chat with the connector on. Asking for examples, stories or "STAR" brings in the full case studies; adding "use the CV tools" keeps answers grounded in the CV.
